# 聚影

使用聚影个人 API Key，在 Muvyo 的资源搜索、订阅和机器人里查找公开影片资源，并可每日自动签到。

## 设置

1. 登录 [聚影](https://www.jying.top/)，进入个人首页的「接入」区域。
2. 验证邮箱后查看或重置个人 API Key。
3. 在插件设置中填写 Key，保存后启用插件。
4. 如需自动签到，在插件设置底部的定时任务里打开「每日签到」。

不需要申请 AppID。API Key 以密钥字段保存，不会在设置页回显。

## 搜索范围

插件先按关键词或 TMDB 编号查找影片，再逐部读取站内有效资源。当前返回 Muvyo 能直接接收的类型：115、123、百度、光鸭、阿里、天翼、磁力和电驴。

聚影返回但 Muvyo 当前不支持接收的类型（例如夸克、迅雷）会被跳过。可以通过「最多匹配影片」控制一次搜索读取的候选影片数；默认 5 部。

## 注意

- 插件只使用聚影公开的个人只读接口和本人签到接口。
- 聚影普通个人 Key 同时只能处理一个请求；插件会顺序读取，不并发请求。
- 个人 Key 的查询限额为滚动 60 秒最多 60 次，请勿把候选影片数设得过大。
- 分享链接是否仍有效以来源站点和网盘实际结果为准。
