# 聚影

在 Muvyo 的资源搜索、订阅和机器人中查找聚影资源，并可每日自动签到。插件支持两种接入方式：仅个人 API Key，或有效 AppID + 用户自己的个人 Key。

## 设置

1. 登录 [聚影](https://www.jying.top/)，进入个人首页的「接入」区域。
2. 验证邮箱后查看或重置自己的个人 API Key。
3. 个人使用时只填写「个人 API Key」，AppID 留空。
4. 已申请并获批 AppID 时，再填写自己的 AppID；插件将自动切换到开发接口和聚合搜索。
5. 如需自动签到，在插件设置底部的定时任务里打开「每日签到」。

API Key 和 AppID 均以密钥字段保存，不会在设置页回显。不要使用或分发 AppID 所有人的 Key；每位用户必须填写自己的 Key。

## 两种模式

### 仅个人 Key

- 使用 `X-API-Key` 和 `/api/read/v1/` 公开只读接口。
- 普通 Key 并发为 1，查询限额为滚动 60 秒最多 60 次。
- 插件顺序请求，不并发；相同搜索缓存 5 分钟，减少重复调用。
- 除本人签到专用入口外，不执行 POST、上传、发布、修改或删除。

### AppID + 个人 Key

- 使用 `X-App-Id` 标识应用，`X-App-Key` 标识当前用户。
- 搜索走聚合接口，一次返回聚影站内与 PanSou 结果；限额为每个凭证 20 次/分钟，结果缓存 3 分钟。
- 其他开发接口按共享用户最严格的 10 次/分钟保护，兼容 AppID 所有人和其他用户的规则。
- 每个 Key 同时只能绑定一个 AppID。遇到绑定冲突时，插件会提示用户前往聚影个人首页验证邮箱并确认换绑，不会自动切换。

两种模式收到 `429` 后都会遵循 `Retry-After` 进入冷却，不会密集重试。重置 Key 不会清除服务端限流记录。

## 搜索范围

当前返回 Muvyo 能直接接收的类型：115、123、百度、光鸭、阿里、天翼、磁力和电驴。聚影返回但 Muvyo 当前不支持接收的类型（例如夸克、迅雷）会被跳过。

仅个人 Key 模式会先查找影片，再顺序读取候选影片资源；可通过「最多匹配影片」控制请求数量，默认 5 部。AppID 模式将该设置用作聚合接口的站内影片上限。

## 注意

- 仅用于合理的交互式搜索和本人签到，避免高频或持续自动调用。
- 不要在日志、网址、公开仓库或反馈内容中保存完整 Key。
- 分享链接是否仍有效，以来源站点和网盘实际结果为准。
- 完整规则以 [聚影 API 开发者指南](https://www.jying.top/api-developer-guide#personal-access) 为准。
