# ZhhHugoChang 的 Muvyo 插件

Muvyo 第三方插件仓库。在 Muvyo「第三方插件 → 插件仓库」添加本仓库地址，即可安装和更新插件。

仓库地址：`https://github.com/ZhhHugoChang/muvyo-addon`

## 插件

| 插件 | 说明 | 需要准备 |
|---|---|---|
| 聚影（`zhhhugochang.jying`） | 按关键词或 TMDB 编号搜索聚影资源，支持个人 API 与 AppID 聚合模式、每日签到 | 聚影个人 API Key；AppID 可选 |

聚影插件返回 Muvyo 可接收的 115、123、百度、光鸭、阿里、天翼、磁力和电驴资源；夸克、迅雷等 Muvyo 当前不能接收的类型会自动跳过。

## 安装

1. 在 Muvyo 打开「第三方插件 → 插件仓库」。
2. 添加 `https://github.com/ZhhHugoChang/muvyo-addon`。
3. 安装“聚影”，填写从聚影个人首页取得的 API Key；如已获批 AppID，可同时填写，然后启用。
4. 如需自动签到，在插件设置底部启用“每日签到”任务。
